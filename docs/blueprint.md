# **App Name**: Nexus Laptop

## Core Features:

- Intelligent Spec Advisor Tool: An AI-powered tool that provides expert summaries of laptop specifications and recommends compatible accessories based on performance needs.
- Modern Catalog Interface: A high-performance product browsing experience with instant searching, category filtering, and inventory status visibility.
- Secure Auth & Session Recovery: Enterprise-grade authentication system using Supabase, featuring email, Google social login, and robust session persistence across refreshes.
- Syncing Shopping Cart: Real-time cart management that synchronizes product quantities and preparation status with the user's database record.
- Command Admin Dashboard: Centralized panel for authorized administrators to manage inventory, product images, and track sales data.
- Storage-Optimized Profiles: Individual user profiles with order history and Supabase Storage integration for high-quality image uploads.
- Responsive Order Management: A secure order pipeline tracking every transaction with unique relational identifiers for hardware auditing.

## Style Guidelines:

- Primary Color: #3E5BFF (vibrant tech indigo) to represent engineering precision and digital fluidity.
- Background Color: #13151D (deep obsidian blue), a heavily desaturated variant that creates a premium dark-mode depth.
- Accent Color: #8F66FF (refined purple), chosen for high contrast and modern navigational emphasis.
- Headline font: 'Space Grotesk' (sans-serif) for its technical, scientific character; Body font: 'Inter' (sans-serif) for machine-like legibility and professional neutrality.
- A responsive, mobile-first grid with edge-to-edge tech banners and precision-engineered cards with minimal padding and clear hierarchical borders.
- Sleek, monolinear icons with light weighting to match the technical aesthetic of the hardware catalogs.
- Smooth micro-interactions and hardware-accelerated transitions to simulate the high performance of the products being sold.
